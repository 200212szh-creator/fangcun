# 首页覆写规范：方寸真实数据工作台

首页 `/home` 是进入藏书室后的真实工作台。Hero 只用简洁标题“我的藏书”（English: “My books”），下面紧接真实统计、最近入藏和数据库书架位置。

- 主色保持 `--navy`、`--brass`、`--parchment` 语义令牌，不复制参考页面品牌、文案、商标或外部媒体。
- 统计数字必须来自 catalog/research API；空库显示 0，不显示演示书目或解释性假数据。
- 书架名称、层级标签和数量必须来自 `ShelfLocation` 与 owned-copy location 计算；没有书架时显示创建第一个位置的行动。
- Hero 可使用短版深藏青渐变，工作内容使用不透明纸张表面、细边框和稳定信息密度；不依赖远程视频。
- 中文标题使用系统宋体回退，英文标题优先 Instrument Serif；正文优先 Plus Jakarta Sans + 中文系统字体栈。
- 首页只保留一个主操作“添加一本书”，搜索作为次级操作；应用壳的顶部不重复放置添加按钮。
- 所有互动目标至少 44×44px，按钮/卡片使用 150–300ms transition，`prefers-reduced-motion` 时展示完整内容并关闭动效。

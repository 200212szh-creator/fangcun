# 动效章节：安静、克制、可打断

方寸的动效只解释状态变化、空间关系或操作结果，不承担装饰。动效不是加载、成功或失败的唯一信息；文字、图标、`aria-live` 和原生控件状态始终保留。

## 全局令牌

| 令牌 | 值 | 用途 |
|---|---:|---|
| `--motion-press` | `90ms` | 按压反馈 |
| `--motion-fast` | `140ms` | 关闭、退出、短淡出 |
| `--motion-base` | `180ms` | 标签、按钮、提示状态 |
| `--motion-slow` | `260ms` | 主内容和抽屉进入 |
| `--ease-standard` | `cubic-bezier(.2, 0, 0, 1)` | 状态切换 |
| `--ease-enter` | `cubic-bezier(.16, 1, .3, 1)` | 进入 |
| `--ease-exit` | `cubic-bezier(.4, 0, 1, 1)` | 退出 |

单次界面动画不超过 400ms。位移以 1–4px 为主；移动抽屉从左侧进入 16px，退出更快。只声明实际变化的 `transform`、`opacity`、颜色、边框和阴影属性，不使用 `transition: all`。

## 语义原语

- `motion-page-in`：仅主内容首次进入时透明度加 4px 位移；应用外壳、侧栏和顶栏保持稳定。
- `motion-drawer-in/out` 与 `motion-backdrop-in/out`：移动抽屉与遮罩分离控制，支持 Escape、遮罩点击、导航关闭和焦点返回。
- `motion-feedback-in`：成功、失败和提示以文字/图标为主，配合 2px 淡入。
- `motion-crossfade`：同一容器中的加载、空状态、结果和错误替换使用短淡入。
- `motion-list-in`：只用于首次结果揭示的前 4 项，间隔 25ms；重检索使用整体交叉淡化。
- `motion-press`：交互控件按压缩放至 `.99`，不改变布局边界。
- `motion-book`：仅书籍卡片、封面或真实格位聚焦/悬停时上移 1px。
- `motion-skeleton`：超过 300ms 的请求才显示统一 shimmer；数据到达立即移除。
- `motion-disclosure-icon/content`：详情展开只旋转箭头并淡入内容，不动画高度。

## 禁止项

- 不再使用无语义的 `page-enter`、`stagger-item`、`success-flash` 或 `feedback-pop`。
- 普通信息卡片不统一上浮，不用大范围成功光圈，不用抖动表达错误。
- 不用动画阻塞路由、输入和快速连续操作；旧请求和旧加载提示必须可取消/清理。
- 不使用持续漂浮、循环呼吸、视差、字符拆分或超过 400ms 的装饰动画。

## 减少动态效果

`prefers-reduced-motion: reduce` 会关闭动画、过渡、平滑滚动、列表错峰和骨架 shimmer，并清除书封/书架格位位移。抽屉立即关闭，导航不等待退出计时器；状态文字、图标、焦点和原生禁用状态保持可用。

## 验收基线

覆盖 1440px、390px、375px、横屏、键盘/触控、快速切换、移动抽屉、添加/检索、保存成功与失败、详情展开、借阅和批注状态。重点观察：无横向溢出、无固定导航遮挡、无布局跳动、无遮罩残留，且生产包不引入新的大型动效依赖。

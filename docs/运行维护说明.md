# 方寸本地长期运行与维护说明

本文档对应当前已安装的 Windows 本地运行版本。应用代码在 `D:\图书库`，真实数据和运行日志在 `D:\方寸数据`，两者分离，升级代码不会覆盖藏书数据。

## 日常使用

- 桌面快捷方式：当前用户桌面上的“方寸”。
- Windows 登录后，任务 `Fangcun Archive Service` 会在约 20 秒内启动服务。
- 需要打开页面时双击“方寸”快捷方式；只有健康检查通过后才会打开 `http://localhost:3000/`。
- 不要用开发模式作为日常服务，不要直接复制覆盖 `D:\方寸数据\data\library.db`。

## 固定目录

```text
D:\方寸数据\
├─ data\library.db                 真实 SQLite 数据库
├─ covers\                         封面资源
├─ backups\daily\                 每日备份，保留最近 21 个有效日
├─ backups\pre-upgrade\           发布或升级前备份
├─ backups\media\                 媒体备份
├─ config\service.env             服务环境配置
├─ logs\service\                  应用服务日志
├─ logs\watchdog\                 看门进程日志
├─ logs\launcher\                 启动器日志
├─ state\                          PID、健康状态和当前版本指针
├─ recovery\                       损坏数据库、恢复前旧库和恢复临时文件
└─ quarantine\                     清理前暂存的旧启动入口与测试文件
```

## 健康检查

打开 `http://localhost:3000/api/health`。健康时返回 `status: ok`、`database: ok` 和当前 `buildId`；接口不返回书名、作者、借阅人、批注或其他隐私数据。

如果页面打不开，先等待 60 秒。启动器会尝试唤醒 Windows 任务并等待健康检查；仍失败时使用启动器里的“查看日志”或“打开恢复目录”，不要反复启动多个服务。

## 发布新版本

在 `D:\图书库` 打开 PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-release.ps1 -Version 2026-09-08_170000
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\promote-release.ps1 -ReleaseDir .\runtime\releases\2026-09-08_170000
```

版本目录必须是新的、完整的 standalone 构建。提升版本前会先做经过完整性校验的升级前备份；切换指针后由常驻任务重新拉起服务。升级后检查 `/api/health`、首页、添加图书、检索、分类与位置、设置页，并确认藏书数量没有变化。

## 备份与恢复

每日备份由常驻任务在当天首次启动时执行，备份和元数据都必须通过 SQLite 完整性检查。备份脚本也可以手动执行：

```powershell
$env:FANGCUN_DATA_DIR = 'D:\方寸数据'
$env:DATABASE_URL = 'D:\方寸数据\data\library.db'
node .\runtime\maintenance\database-maintenance.js --mode=daily
```

恢复前先停止服务任务，再从 `D:\方寸数据\backups\daily` 或 `pre-upgrade` 选择一个对应的 `.db` 文件。恢复脚本会先把当前数据库移入 `recovery`，在临时文件上校验完整性和关键表，再原子替换正式数据库：

```powershell
Stop-ScheduledTask -TaskName 'Fangcun Archive Service'
node .\runtime\maintenance\restore-database.js --source 'D:\方寸数据\backups\daily\fangcun-daily-YYYY-MM-DD.db' --data-root 'D:\方寸数据' --confirm
Start-ScheduledTask -TaskName 'Fangcun Archive Service'
```

恢复后必须检查 `/api/health` 和页面数据。若完整性检查失败，服务会拒绝启动，并把可疑数据库留在 `D:\方寸数据\recovery`，不会静默覆盖。

## 服务与日志

- 任务名称：`Fangcun Archive Service`。
- 服务监听：`127.0.0.1:3000`，只接受本机访问。
- 任务失败时由 Windows 负责基础重试，看门进程还会进行健康检查、退避重启和每小时重启次数限制。
- 日志按服务、看门进程、启动器分开保存，单文件约 5 MB、按 14 天和总量约 100 MB 清理。
- 日志会过滤 API key、token、密码、借阅联系人、批注正文等敏感字段；排障时优先查看 `D:\方寸数据\logs`。

## 重新安装或更换账户

以管理员身份打开 PowerShell，在项目目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-fangcun.ps1 -ProjectRoot 'D:\图书库' -DataRoot 'D:\方寸数据'
```

脚本会更新任务、桌面快捷方式和开始菜单快捷方式，不会删除 `D:\方寸数据`。更换账户时应重新创建该账户的快捷方式，并确认该账户对固定数据目录具有最小必要的修改权限。

## 登录自启三层保障

- 主任务 `Fangcun Archive Service`：当前用户登录后延迟约 15 秒启动隐藏看门进程；启用 `StartWhenAvailable`、无限执行、忽略重复实例和失败重启。
- Startup 恢复：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\方寸后台恢复.lnk` 通过 `wscript.exe` 隐藏启动 `startup-recovery.ps1`。它先等待服务，再触发主任务，最后以隐藏方式启动持久看门进程；不会自动打开浏览器。
- 周期健康恢复：`Fangcun Archive Health Recovery` 每 5 分钟隐藏运行一次健康检查，主任务或登录会话被中断时负责兜底恢复；健康时快速退出，不重复启动或重复备份。

重启后一次性验收会写入 `D:\方寸数据\state\post-reboot-verification.json` 和 `.txt`，成功或失败都会落盘，完成后自动删除自身任务。失败时保持数据库不变，优先查看 `D:\方寸数据\logs\launcher\startup-recovery-YYYY-MM-DD.log`、`watchdog` 日志和 `recovery` 目录。

## 卸载开机任务

如需停止开机自启但保留数据，可执行：

```powershell
Unregister-ScheduledTask -TaskName 'Fangcun Archive Health Recovery' -Confirm:$false
Unregister-ScheduledTask -TaskName 'Fangcun Archive Service' -Confirm:$false
Remove-Item -LiteralPath (Join-Path ([Environment]::GetFolderPath('Startup')) '方寸后台恢复.lnk') -Force
```

这只移除任务和 Startup 快捷方式，不删除 `D:\方寸数据`、正式数据库、备份或恢复文件。需要恢复自启时重新运行安装脚本即可。

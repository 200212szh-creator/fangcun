# 方寸使用说明

## 第一次添加图书

打开“添加图书”，只输入书名，选择正确的作者和版本后保存。若网络书目暂时不可用，或没有找到旧书，可切换到“完全手动录入”；书名和作者是必填项，其余资料按需展开填写。无 ISBN 也能保存。

## 建立书架位置

打开“分类与位置”，新建一个实际位置，例如“书房东墙 / A 架”。回到图书详情，选择该书架并填写层或格。一个版本可以保存多册实体书，每一册都有自己的位置、来源、价格和品相。

## 借出与归还

打开一本书的详情，在“借阅记录”填写借阅人和应还日期。到期未还会显示“已逾期”；需要延期时直接填写新的归还日期并点“续借”。归还后，记录会进入历史，同一册才可再次借出。

## 批注与概念

在详情页填写页码或章节、批注内容和概念。多个概念可用逗号分隔。使用“跨书检索概念”后，结果会显示在当前页面，并可点“打开原书”回到对应档案。

## 备份与恢复

- 日常便携备份：在“设置”中导出 JSON；CSV 更适合在表格软件中查看。
- 完整数据库备份：关闭方寸后，在项目目录运行 `npm run db:backup`。文件保存在 `artifacts/db-backups`。
- 安全恢复检查：不要覆盖正在使用的数据库。先运行 `npm run db:restore -- <备份文件> <新的数据库文件>` 恢复到新文件，确认可打开后再决定是否替换正式库。

## 功能限制与降级

- 书名、ISBN 和文献检索依赖公开第三方接口；接口不可用时会明确提示，可重试或改用手动录入。
- 摄像头扫码依赖浏览器、摄像头权限和设备支持；不可用时可手动输入 ISBN。
- 方寸不会自动向借阅人发送提醒，也不会在应用关闭后推送系统通知；逾期状态只在应用内显示。
- 二维书架只显示已保存的真实书架与格位；未填写格位的图书会被列为“尚未填写格位”，不会虚构位置。
- QR 书标只包含本地副本编号。换电脑后，需要同时恢复对应数据库才能打开原记录。

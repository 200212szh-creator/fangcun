# 方寸 Editorial Atelier 全站复刻实施方案

> 状态：Approved for implementation  
> 日期：2026-09-08  
> 唯一视觉基准：`design-system/default/references/fangcun-editorial-home-v2.png`  
> 实施原则：视觉完整复刻、功能零退化、真实数据优先、分阶段定向验收、通过后自动进入下一阶段。

## 1. 目标与边界

把当前方寸全部界面统一为“新古典编辑出版质感（Editorial Atelier）”。首页在 1440×1024 下以视觉基准图为唯一真相；其余页面从同一设计语言派生，不得保留旧式后台卡片风格。

本次是现有 Next.js 应用的原位升级，不新建替代项目，不改动既有业务含义，不清空、覆盖或重新填充数据库，不把演示数据写入正式库，不破坏现有本地常驻服务、备份、恢复、启动器和固定数据目录。

### 不可妥协项

1. 所有现有路由、按钮、表单、搜索、筛选、保存、导入导出、借阅、批注、二维码、书架管理等功能继续可用。
2. 正式数据只来自数据库；空状态显示真实的 0 或引导，不创建虚拟书目、虚拟统计和虚拟位置。
3. 真实封面优先；缺少封面时使用统一的本地纹理底图加动态文字排版，书名必须完整可读。
4. 首页只展示精选或最近入藏的少量记录；上百本或上千本藏书由可搜索、筛选、分页/虚拟化的目录承载。
5. 桌面、平板、移动端及减少动态效果模式使用同一视觉语言，不做“桌面新版、移动端旧版”。
6. 未通过功能与视觉验收不得升级正式发行版本。

## 2. 视觉系统

### 2.1 色彩

所有组件只使用语义令牌，不在页面中散落临时颜色。

| 令牌 | HSL | 用途 |
|---|---|---|
| `--parchment` | `42 30% 96%` | 全站羊皮纸背景 |
| `--surface` | `0 0% 100%` | 高亮工作面 |
| `--surface-strong` | `42 24% 91%` | 次级区块和选中底色 |
| `--ink` | `220 34% 14%` | 正文与主要图标 |
| `--navy` | `210 51% 25%` | 导航、主操作、书布 |
| `--brass` | `39 100% 30%` | 唯一强调色，画面占比约 2% |
| `--border` | `214 32% 83%` | 发丝线与分隔 |

黄铜色不作为大段小字号正文；文本对比度至少 4.5:1。成功、警告、错误保留语义差异，不能只靠颜色表达。

### 2.2 排印

- 展示与书名：本地 `Instrument Serif`；中文回退 `Songti SC`、`STSong`、`SimSun`、serif。
- 正文与控件：本地 `Plus Jakarta Sans`；中文回退 `Microsoft YaHei UI`、`Microsoft YaHei`、`PingFang SC`、sans-serif。
- 坐标与书目参数：`JetBrains Mono` 或 `ui-monospace`，只用于 ISBN、年份、页码、书架坐标和档案编号。
- 正文桌面 15–16px，移动端不低于 16px，行高 1.5–1.75。
- 书名不使用单行省略隐藏关键信息；长标题应换行并按容器缩放字号。
- 运行时字体必须本地可用并使用 `font-display: swap`，不依赖外网字体服务。

### 2.3 栅格、边线与层次

- 桌面采用 12 列编辑栅格与 8px 基础间距体系。
- 32×32px 底纸网格只出现在入口页、首页和页面标题留白区，内容密集区使用纯净不透明表面。
- 先使用留白、对齐、字阶和分隔线建立层次；仅在必要时使用底色和边框；阴影最后使用且只服务于真实书籍、抽屉和遮罩关系。
- 默认圆角控制在 0–6px；不得回到大面积 12–16px 卡片和“卡片套卡片”。
- 图标统一使用现有图标库和品牌标记；不使用 emoji、文本符号或临时手绘图标替代。

### 2.4 图像与材质资产

从视觉基准拆分并制作项目本地资产：纸张细纹、木质悬挑书架、藏青书布纹理、黄铜细节。资产需要有明确尺寸、裁切和使用组件；禁止把整张效果图当网页背景。

- 纸张纹理应极轻，不能降低文字对比度。
- 木质书架只用于首页精选模块和实体位置可视化，不用于完整目录。
- 动态书封使用本地书布纹理作为真实图片底层，标题、作者和档案编号作为可访问的界面文字。
- 所有书封预留固定比例与尺寸，避免加载时布局跳动；真实图片使用 Next Image 优化与延迟加载。

## 3. 全局交互与动效

| 场景 | 时长 | 规则 |
|---|---:|---|
| 按压 | 90ms | 最大缩放 `.99`，不改变布局 |
| 快速退出 | 140ms | 退出快于进入 |
| 普通状态 | 180ms | 颜色、边线、轻微透明度 |
| 内容进入 | 220–260ms | 最大位移 4px |
| 抽屉打开 | 280–320ms | transform + opacity |
| 抽屉关闭 | 180–220ms | 可打断，焦点返回触发器 |
| 书脊悬停 | 180–260ms | 上移 2–4px，不依赖悬停完成操作 |
| 书脊选中 | 220–300ms | 上移 6–8px、回正，缩放不超过 1.01 |

禁止 `transition: all`、弹跳、持续漂浮、视差、字符拆分、全页重复入场和动画高度。超过 300ms 的请求才显示骨架；内容到达立即清理。`prefers-reduced-motion` 只关闭方寸自己的动态类，不使用全局通配符破坏组件逻辑。

## 4. 全局应用外壳

### 桌面

- 统一为视觉基准中的 64px 顶部主梁：品牌、一级导航、全局检索。
- 一级顺序固定：`首页 / 藏书 / 添加图书 / 检索 / 心愿单 / 论文资料夹 / 分类与位置 / 设置`。
- 当前页面使用文字、黄铜短下划线和语义状态共同标识，不使用大胶囊背景。
- 全局搜索提交后进入 `/search?q=...`，键盘和屏幕阅读器均可操作。

### 移动端

- 底部只保留五项：`首页 / 添加 / 藏书 / 检索 / 更多`。
- “更多”抽屉承载心愿单、论文资料、分类位置、导入和设置。
- 触控目标至少 44×44px；保留安全区；320px 宽度无横向滚动。

## 5. 页面实施矩阵

### `/` 进入页

- 与全站同色、同字、同材质；完整展示中英德三行品牌语。
- 单一主操作“进入方寸”，语言切换与“下次直接进入”降为次级。
- 视觉书架是品牌资产而非虚构藏书；不得显示虚拟书名或虚假数量。
- 深链接不受进入页偏好影响。

### `/home` 首页

- 在 1440×1024 下完整复刻视觉基准的布局比例、标题、书架、右侧档案栏、最近入藏行和黄铜主按钮。
- 所有数量、书籍、位置、批注来自真实接口；当前只有一本时只显示一本。
- 精选书架最多显示 5 本，可由最近入藏/收藏逻辑选择；超过数量不继续压缩书脊。
- `查看全部藏书` 进入 `/library`；`添加一本书` 进入 `/add`。
- 无藏书时保留整体版式，以空书架和一个明确添加动作引导，不伪造书籍。

### `/library` 藏书目录

- 使用编辑目录而非大卡片墙；提供封面墙、标准列表、紧凑目录三种密度。
- 支持搜索、状态/作者/分类/标签/位置筛选、排序、清空筛选和深链接查询参数。
- 上百本时使用服务端分页或列表虚拟化，不能一次渲染全部封面。
- 支持进入详情以及现有的批量/单项业务动作；空、加载、失败状态均有恢复路径。

### `/add` 添加图书

- 视觉采用“入藏登账侧滑纸/账簿页”，但保留完整路由和可直接访问性。
- 三种模式完整保留：书名匹配、ISBN/扫描、完全手动。
- 书名搜索显示候选、可信度和版本数量；选择后比较出版社、年份、ISBN、装帧等版本信息。
- 保存前检查疑似重复，允许明确选择新增副本或返回已有记录。
- 保存位置、层格、阅读状态及完整版本字段；网络失败时可重试或转手动，不能丢失已输入内容。

### `/search` 网络检索

- 书籍与论文使用同一检索页，结果以发丝分隔的出版目录行呈现。
- 保留类型切换、取消旧请求、耗时反馈、无结果建议、加入心愿单、保存论文等行为。
- 不能生成备用虚构结果；来源和可用字段需要明确显示。

### `/books/[copyId]` 藏书详情

- 采用视觉基准右侧档案语言扩展成完整档案页。
- 完整书名、作者、封面、版本、实体副本、位置、状态、借阅、批注和书目字段全部可读可编辑。
- 二维码区域必须解释用途；二维码写入稳定副本 ID/可解析地址，扫码应能打开对应记录或给出启动本地服务提示。
- SVG/PNG 书标下载继续可用；生成封面必须完整显示长书名。
- 次要字段分组折叠，但不能以截断隐藏数据。

### `/wishlist` 心愿单

- 使用目录行与侧边详情，不使用独立大卡片。
- 保留删除、查找版本、转为已入藏等现有业务；状态反馈靠文字、图标和颜色共同表达。

### `/research` 论文资料夹

- 使用“对开眉批”语言：左侧文献信息与摘要，右侧私人批注和关联藏书。
- 保留现有保存、查看和管理行为；DOI、作者、年份使用书目排印，不强制单行截断。

### `/manage` 分类与位置

- 分类、书架、标签仍可新增、编辑、排序、启停、删除。
- 长位置名称完整显示或自然换行，不能依赖悬停才能读全。
- 真实位置图只绘制数据库中存在的书架与副本；大量书架时分组/折叠，不做无界面宽度的格子墙。

### `/import` 导入

- 保留上传、预览、字段映射/错误提示和确认写入流程。
- 预览与正式写入必须分离；错误靠近对应行；取消不会改动数据库。

### `/settings` 设置

- 语言、数据导出、导入入口、进入页偏好及已有设置全部保留。
- 数据与运行状态使用档案清单式布局；危险操作必须清晰区分并二次确认。

## 6. 分阶段实施

### R1：安全基线与视觉资产

1. 记录正式数据库路径、核心表真实计数和当前健康状态。
2. 创建升级前备份并验证可读性；不得复制测试数据进正式库。
3. 将视觉基准、颜色、字体、栅格、动效和资产用法写入 Master 设计系统。
4. 制作并检查本地纸张、书架和书布资产。

通过标准：数据计数不变；资产可本地加载；无远程字体/关键图像依赖；定向类型检查与设计令牌测试通过。

### R2：全局外壳、进入页与首页

1. 重构应用外壳和响应式导航。
2. 完整统一进入页。
3. 按基准图复刻首页及 0、1、5、100+ 数据规模下的布局策略。
4. 完成全局搜索、添加、查看详情、查看全部藏书等主路径。

通过标准：1440×1024 首页与基准图对照无 P0/P1/P2 差异；375px/390px 可用；上述主路径实际可点击完成；真实数据未变化。

### R3：高频工作流

实施藏书目录、添加图书、网络检索和藏书详情。先逐页改造，再只运行与该页相关的测试；每页通过后进入下一页。

通过标准：书名匹配→选择版本→指定位置→保存、ISBN/扫描、手动录入、目录筛选、网络检索、详情编辑、借阅、批注、二维码与书标全部完成定向端到端测试。

### R4：次级工作流

实施心愿单、论文资料、分类与位置、导入和设置。

通过标准：每个现有增删改查动作可用；长文本和空状态不破版；导入预览不会提前写库；移动端路径可达。

### R5：全局一致性、性能与无障碍

统一加载、空、错误、保存中、成功、禁用、悬停、聚焦、选中、抽屉开合状态。完成键盘、触控、减少动态、图片加载和大列表性能优化。

通过标准：正常文字对比度 ≥4.5:1；全部核心控件键盘可达；触控目标 ≥44px；320–1440px 无非预期横向滚动；无新增大型动效依赖；100+ 图书测试数据仅存在隔离测试库。

### R6：视觉 QA、功能回归与正式升级

1. 以 1440×1024 捕获首页相同状态，与视觉基准放入同一比较输入。
2. 对入口、首页、目录、添加、检索、详情、研究、位置、设置分别捕获桌面和移动关键状态。
3. 对字体、间距、颜色、资产质量、文案逐项评估；修复所有 P0/P1/P2 后重新截图比较。
4. 最终只运行一次完整 lint、typecheck、单元、数据库集成、端到端和生产构建，不在每个阶段重复无关全套测试。
5. 通过现有发布脚本生成新 release；保持 `D:\方寸数据`、备份和启动任务不变；健康检查通过后再切换正式版本。

通过标准：项目根目录 `design-qa.md` 的 `final result: passed`；关键路由无控制台错误；全部核心功能回归通过；正式库前后计数符合预期；启动器、后台恢复和健康检查正常。

## 7. 定向测试矩阵

| 区域 | 必测路径 |
|---|---|
| 进入页 | 三语品牌、语言切换、直接进入偏好、深链接 |
| 首页 | 0/1/5 条数据、选书、详情、查看全部、添加 |
| 藏书 | 搜索、组合筛选、排序、视图切换、分页/虚拟化、空结果 |
| 添加 | 书名匹配、版本比较、重复判断、ISBN、扫描、手动、失败恢复、保存 |
| 详情 | 编辑版本、副本位置、状态、借阅、批注、二维码、SVG/PNG |
| 检索 | 书/论文切换、旧请求取消、无结果、网络失败、保存目标 |
| 整理 | 分类/标签/位置增改排序启停删除、长名称、真实位置图 |
| 数据 | 导入预览/提交/错误、JSON/CSV 导出、正式库完整性 |
| 全局 | 桌面/移动导航、键盘、焦点、减少动态、快速切换、服务健康 |

## 8. 视觉 QA 交付物

- `design-qa.md`：必须记录视觉基准路径、实现截图路径、视口、像素尺寸、状态、完整视图和重点区域比较。
- `artifacts/editorial-atelier/`：存放逐轮截图与比较证据，不放进正式运行数据目录。
- 比较历史：每轮列出原 P0/P1/P2、修复内容和修复后证据。
- 最终允许保留 P3 微调建议，但 P0/P1/P2 必须为零。

## 9. 禁止事项

- 禁止用整张效果图充当页面背景冒充复刻。
- 禁止只改首页而让其他路由保留旧卡片系统。
- 禁止为“画面更丰富”向正式数据库添加样例书、样例论文或样例书架。
- 禁止删除、重建、覆盖正式数据库；禁止改变固定数据和备份目录。
- 禁止在尚未验收时替换正式 release。
- 禁止以构建成功或健康接口 200 代替浏览器功能与视觉验收。

## 10. 完成定义

只有同时满足以下条件才可报告完成：

1. 全部页面采用统一 Editorial Atelier 视觉系统。
2. 首页通过与确认效果图的同状态视觉对照。
3. 所有现有核心功能完成真实交互测试且无退化。
4. 0、1、5、100+ 数据规模均有隔离测试覆盖，正式库没有测试数据。
5. 桌面、移动、键盘和减少动态模式通过。
6. `design-qa.md` 为 `final result: passed`。
7. 正式升级后服务健康、数据完整、备份与自动恢复机制不受影响。
